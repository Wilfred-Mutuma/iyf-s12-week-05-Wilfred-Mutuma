## Project Overview

This repository contains my Week 5 JavaScript practice. I learned how to select and modify HTML elements, traverse the DOM, create and remove elements, and respond to user interactions using JavaScript events.

## Main Project: To-Do List Application

The main application is available in `index.html`.

### Features

- Add tasks using the Add button or Enter key.
- Mark tasks as completed.
- Delete individual tasks.
- Filter tasks by All, Active, and Completed.
- Display the number of remaining tasks.
- Clear completed tasks.
- Edit tasks using the Edit button.

## DOM Practice Tasks

The `dom-practice.html` page and `dom.js` file contain practice with:

- Selecting elements using different DOM methods.
- Traversing parent, child, and sibling elements.
- Modifying text, HTML, attributes, data attributes, and styles.
- Creating, appending, cloning, and removing elements.
- Adding navigation items dynamically.
- Handling click, keyboard, and input events.
- Using event delegation.
- Validating form submissions.

## Daily Challenges

1. **Day 1 — Color Changer:** Changes the page background color.
2. **Day 2 — Dynamic Element Creator:** Adds new list items.
3. **Day 3 — Image Remover:** Removes image cards from the page.
4. **Day 4 — Content Copier:** Copies content into another section.
5. **Day 5 — Dark Mode Toggle:** Switches between light and dark themes.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser to use the To-Do List.
4. Open `dom-practice.html` to review the DOM practice tasks.
5. Open the HTML files inside `daily-challenges/` to test each challenge.
